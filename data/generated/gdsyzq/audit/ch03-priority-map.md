# 第 3 章《债券收益率》复习价值分层图

编辑日期：2026-05-12

## 1. 本章复习定位

第 3 章是后续债券定价、无套利估值、利率风险和信用利差分析的利率基础。期末复习的主线不是把所有收益率概念平均背一遍，而是沿着“收益来源 → 收益率指标 → 即期利率曲线构造 → 远期利率 → 期限结构理论”建立判断路径。

最可能考查的题型：

- 计算当期收益率、到期收益率相关报价口径和债券等值收益率。
- 比较当期收益率、到期收益率、即期收益率与远期利率的适用边界。
- 根据给定现金流、短端即期利率和债券价格使用自展法求未知即期利率。
- 根据即期利率推出远期利率，或根据远期利率反推长期即期利率。
- 识别收益率曲线四种形态。
- 比较纯预期理论、流动性偏好理论、偏好理论和市场分割理论能解释什么。
