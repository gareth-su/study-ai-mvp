## Payoff Chart 验算

### VB[8] 四类期权头寸到期收益图

参数：K=50, c=5, p=4

**买入看涨（Long Call）**：
| x | 公式：max(S_T-K,0)-c | chart y | 一致 |
|---|---|---|---|
| 20 | 0-5 = -5 | -5 | ✓ |
| 50 | 0-5 = -5 | -5 | ✓ |
| 55 | (55-50)-5 = 0 | 0 | ✓ (breakeven=55) |
| 80 | (80-50)-5 = 25 | 25 | ✓ |

**卖出看涨（Short Call）**：
| x | 公式：-max(S_T-K,0)+c | chart y | 一致 |
|---|---|---|---|
| 20 | 0+5 = 5 | 5 | ✓ |
| 50 | 0+5 = 5 | 5 | ✓ |
| 55 | -(5)+5 = 0 | 0 | ✓ |
| 80 | -(30)+5 = -25 | -25 | ✓ |

**买入看跌（Long Put）**：
| x | 公式：max(K-S_T,0)-p | chart y | 一致 |
|---|---|---|---|
| 20 | (50-20)-4 = 26 | 26 | ✓ |
| 46 | (50-46)-4 = 0 | 0 | ✓ (breakeven=46) |
| 50 | 0-4 = -4 | -4 | ✓ |
| 80 | 0-4 = -4 | -4 | ✓ |

**卖出看跌（Short Put）**：
| x | 公式：-max(K-S_T,0)+p | chart y | 一致 |
|---|---|---|---|
| 20 | -(30)+4 = -26 | -26 | ✓ |
| 46 | -(4)+4 = 0 | 0 | ✓ |
| 50 | 0+4 = 4 | 4 | ✓ |
| 80 | 0+4 = 4 | 4 | ✓ |

**结论：16/16 数据点全部验算正确。** Breakeven 正确：long call 55 (K+c)，long put 46 (K-p)。
